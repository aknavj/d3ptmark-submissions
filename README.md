# Doom3 PT benchmark | Submissions

Here you can submit the benchmark results for public leaderboard to compete with others by opening the issue.

# How To?

1. Find reports under your engine’s save path:

```
base/screenshots/ptreports/benchmark/run_NNNNN/
```

2. ZIP `metadata.json`, `frames.csv`, `settings.csv`, and optional `telemetry.csv`. 

3. Choose one preview image, not the full image sequence. 

4. Review the ZIP for private paths and arguments. 

5. Never include game data or keys.

6. Submit issue then wait.

> Results need maintainer approval (`benchmark-approved`). This is community review, not independent verification. Dirty or unknown revisions stay unranked.
